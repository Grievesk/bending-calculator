Sheet metal bending calculator

Grievesk Bend is a free technical project for sheet metal bending professionals. It provides calculation tools and practical references for K-factor, flat pattern development, V-die openings, internal radius and bending force.

The calculator application is currently available on the main page. The English information pages are available below; the calculator interface is still being prepared for full English localization and independent metric/imperial unit selection.

About this project

Created and maintained by Paolo Macellaro, drawing on more than 25 years of practical experience in sheet metal bending, press brake tooling and CAD/CAM programming.

Calculation results are indicative and must be checked against the actual material, tooling, machine limits and workshop tests before production use.
